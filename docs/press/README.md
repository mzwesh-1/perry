## Key facts

- Perry is a free, open-source (MIT) programming language for money and finance,
  created in South Africa by Mzwandile Zulu.
- Money is exact: no floating point. Amounts carry their currency, and rates carry
  their period.
- `PERRY --check` finds money mistakes before a program runs, on every path through it.
- In preliminary tests the checker found 98% of deliberately introduced money mistakes,
  with no false alarms on correct programs. A study with university students' programs
  is planned.
